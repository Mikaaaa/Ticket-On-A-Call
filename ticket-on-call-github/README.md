# Ticket sur appel 3CX

Extension Edge/Chrome (Manifest V3).

- Ouvre la page de creation de ticket quand un appel apparait dans le client web 3CX.
- Colle des textes predefinis avec un raccourci clavier (ex : Alt+1).

## Installation
1. edge://extensions puis activer le Mode developpeur.
2. Charger l'extension decompressee et choisir ce dossier.

## Configuration (a adapter)
Les valeurs de ce depot sont des exemples anonymises :
- manifest.json : remplacer example.on3cx.fr et tickets.example.com par vos domaines.
- URL du ticket : modifiable dans la page d'options.
